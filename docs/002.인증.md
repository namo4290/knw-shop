## 2. JWT 인증의 동작 메커니즘

1. **로그인 요청:** Nuxt(클라이언트)가 사용자 ID/PW를 Laravel API로 전송.
2. **토큰 발급:** Laravel은 DB 확인 후 해당 사용자를 위한 고유 문자열(Token)을 생성하여 반환.
3. **토큰 저장:** Nuxt는 받은 토큰을 `localStorage`나 `Cookie`에 저장.
4. **인증 요청:** 이후 모든 API 요청 시 HTTP 헤더에 `Authorization: Bearer {Token}`을 포함하여 전송.
5. **검증:** Laravel은 헤더의 토큰을 확인하여 어떤 사용자인지 식별하고 데이터를 반환.

## 3. Laravel 12 설정 (Sanctum 방식)

먼저 API 기능을 설치합니다. (이미 하셨다면 패스하세요)

```bash
docker-compose exec app php artisan install:api

```

**User 모델 수정 (`app/Models/User.php`)**

```php
use Laravel\Sanctum\HasApiTokens;

class User extends Authenticatable
{
    use HasApiTokens, HasFactory, Notifiable;
    // ...
}

```

**로그인 컨트롤러 예시 (`app/Http/Controllers/AuthController.php`)**

```php
public function login(Request $request)
{
    $user = User::where('email', $request->email)->first();

    if (! $user || ! Hash::check($request->password, $user->password)) {
        return response()->json(['message' => '로그인 실패'], 401);
    }

    // 토큰 발행 (이것이 JWT의 역할을 합니다)
    $token = $user->createToken('mobile-app')->plainTextToken;

    return response()->json([
        'access_token' => $token,
        'token_type' => 'Bearer',
    ]);
}

```

## 4. Nuxt 3 설정 (프런트엔드)

Nuxt에서는 모든 요청에 토큰을 자동으로 붙여주는 **Interceptor**를 구성해야 합니다.

**`frontend/composables/useApi.ts` (예시)**

```typescript
export const useApi = (url: string, options: any = {}) => {
  const token = useCookie("auth_token"); // 혹은 localStorage

  return useFetch(url, {
    baseURL: useRuntimeConfig().public.apiBase,
    ...options,
    headers: {
      ...options.headers,
      Authorization: token.value ? `Bearer ${token.value}` : "",
    },
  });
};
```

## 5. 베테랑을 위한 보안 및 운영 팁

- **토큰 만료 관리:** Sanctum 토큰은 기본적으로 만료 기간이 없습니다. 보안을 위해 `config/sanctum.php`에서 `expiration`을 분 단위(예: 60분)로 설정하시는 것이 좋습니다.
- **CORS 주의:** Nuxt와 Laravel의 도커 포트가 다르므로(3000 vs 8000), `config/cors.php`에서 프런트엔드 주소를 반드시 허용해야 합니다.
- **Filament와의 공존:** Filament 관리자 페이지는 세션(Session) 기반 인증을 쓰고, 모바일 앱 API는 JWT(Token) 기반 인증을 쓰도록 분리됩니다. 라라벨은 이 두 가지를 멀티 가드(`guards`)로 아주 깔끔하게 동시 지원합니다.
